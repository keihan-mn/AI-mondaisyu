最後に、自分のパソコンに保存したHTMLファイルを直接開く場合は、必ずWebサーバーとの通信が発生するのか調べ、Web上のページを開く場合との違いを一つ説明してください。

ブラウザがHTMLを受け取ってから画面を表示するまでの基本的な流れを調べ、自分の言葉で説明してください。

## 第4章　CSSの役割――見た目を整える

CSSは、HTMLで作った内容や構造に対して、色、文字の大きさ、余白、配置などの見た目を指定するための言語です。

### 問題1：セレクター・プロパティ・値は何を表しているのか

```html

```

```css
h1 {
```

CSSで対象を選ぶ部分を「セレクター」、見た目の種類を「プロパティ」、設定する内容を「値」といいます。上のCSSから、セレクター、プロパティ、値をそれぞれ見つけてください。また、HTMLの`class="note"`とCSSの`.note`がどのようにつながっているか説明してください。

> **ヒント：**「CSS セレクター プロパティ 値」「CSS class セレクター」「CSS color font-size」「CSS padding」というキーワードを使って調べてください。

最後に、一つのHTMLファイルだけで試作品を作る場合と、複数のページを持つWebサイトを作る場合について、自分ならどの方法を選ぶか、理由とともに説明してください。この問いには、制作物の規模や目的によって複数の判断があります。

最後に、AIが簡単な色の変化にもJavaScriptを追加した場合、そのまま採用するか、CSSで実現できないか確認するか、自分の判断と理由を書いてください。

### 問題2：イベントが起きると処理はどのように実行されるのか

Webページ上で発生するクリックや文字入力などの出来事を「イベント」といいます。JavaScriptでは、特定のイベントが発生したときに実行する処理を登録できます。

次のコードをHTMLの`<body>`内へ追加し、ブラウザでボタンを押してください。`document.querySelector()`は、指定したセレクターに一致するHTML要素を探す命令です。

```html

<script>
  const greetButton = document.querySelector("#greetButton");

  greetButton.addEventListener("click", function () {
    alert("こんにちは！");
  });

```

このコードについて、`id="greetButton"`と`#greetButton`のつながり、`click`が表すイベント、`function`の中に書かれた処理が実行されるタイミングを説明してください。

そのうえで、表示されるメッセージを変更してください。次に、HTML側の`id`だけを別の名前へ変えた場合に何が起こるかを試し、JavaScript側も同じ名前へ直す必要がある理由を考えてください。

> **ヒント：**「JavaScript イベントとは」「addEventListener click」「document querySelector id」「JavaScript alert」というキーワードを使って調べてください。

### 問題3：条件によって処理を変えるにはどうするのか

JavaScriptでは、値に名前を付けて保存する「変数」や「定数」と、条件によって実行する処理を分ける`if`文を使えます。次のコードでは、`temperature`という定数に気温を表す数値を保存しています。第5章の問題2で作ったHTMLを使い、`<script>`要素の中身を次のコードへ置き換えて実行してください。

```javascript
const temperature = 30;

if (temperature >= 28) {
  message = "暑い日です";
} else {
  message = "過ごしやすい日です";
}

alert(message);
```

コードを上から順番に読み、`temperature`が`30`の場合に表示されるメッセージと、その理由を説明してください。次に、値を`20`と`28`へ変更し、それぞれの結果を確認してください。`>=`が表す比較の意味も調べてください。

最後に、「28度以上」という条件を「25度以上」へ変更する依頼をAIへ出す場合、どの部分だけを変更すればよいでしょうか。意図していない文章や別の処理まで変わっていないことを、どのように確認するか説明してください。

> **ヒント：**「JavaScript const let 違い」「JavaScript if else」「JavaScript 比較演算子 以上」「JavaScript 条件分岐」というキーワードを使って調べてください。

## 第6章　HTML・CSS・JavaScriptが連携する仕組み

HTML、CSS、JavaScriptは、同じWebページの中で役割を分担しながら連携します。この章では、三つのファイルをつなぎ、HTMLの要素をJavaScriptで変更する流れを学びます。

### 問題1：三つのファイルはどのようにつながるのか

同じフォルダーに`index.html`、`style.css`、`script.js`があるとします。次のHTMLでは、どのコードがCSSファイルを読み込み、どのコードがJavaScriptファイルを読み込んでいるか説明してください。

```html
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8">
    <title>三つのファイルの連携</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Webページ</h1>
    <button id="changeButton">表示を変える</button>

    <script src="script.js"></script>
  </body>
</html>
```

`href`属性と`src`属性がそれぞれ何を指定しているか調べてください。また、実際のファイル名が`styles.css`なのにHTMLでは`style.css`と指定した場合と、実際のファイル名が`main.js`なのにHTMLでは`script.js`と指定した場合に、画面へどのような影響が出る可能性があるか考えてください。

最後に、CSSやJavaScriptを一つのHTMLファイルへすべて書く方法と、三つのファイルへ分ける方法を比較し、学習用の小さなページと複数ページのWebサイトではどちらを選ぶか、理由を説明してください。

### 問題2：JavaScriptはHTMLの表示をどう変更するのか

ブラウザは、読み取ったHTMLをJavaScriptから操作できる形にします。この仕組みを「DOM」といいます。次の三つのコードを、それぞれ`index.html`、`style.css`、`script.js`へ保存して実行してください。

```html
  <head>

    <title>DOMによる表示変更</title>

  </head>

    <script src="script.js"></script>
  </body>
</html>
```

```css
.highlight {
  color: white;
  background-color: navy;
  padding: 8px;
}
```

```javascript
const message = document.querySelector("#message");
const changeButton = document.querySelector("#changeButton");

changeButton.addEventListener("click", function () {
  message.textContent = "JavaScriptで変更しました。";
  message.classList.add("highlight");
});
```

ボタンを押したとき、`textContent`と`classList.add()`によって何が変わるか説明してください。また、HTMLの`id`、CSSの`.highlight`、JavaScriptの`#message`と`highlight`が、どのようにつながっているかを図や箇条書きで整理してください。

次に、JavaScriptの`highlight`だけを別の名前へ変え、CSS側を変更しなかった場合に何が起こるか試してください。文章は変更される一方、背景色などの`.highlight`で指定した見た目が反映されない理由を説明し、修正方法をまとめてください。

> **ヒント：**「DOMとは 初心者」「JavaScript textContent」「JavaScript classList add」「CSS class JavaScript 連携」というキーワードを使って調べてください。

### 問題3：一つの機能を三つの技術へどう分けるのか

「説明文とボタンがあり、ボタンを押すたびに説明文の表示と非表示が切り替わるプロフィールカード」を作ることになりました。実装する前に、次の内容をHTML、CSS、JavaScriptのどれが主に担当するか整理してください。

そのうえで、AIへ実装を依頼する文章を作り、生成されたコードを実際に動かしてください。一度目、二度目、三度目とボタンを押し、表示と非表示が交互に切り替わることを確認してください。

最後に、生成されたコードについて、次の三つの観点から確認結果をまとめてください。

この実装には複数の方法があるため、特定のコードだけが正解ではありません。自分が採用した方法と、そのコードを理解できると判断した理由も説明してください。

> **ヒント：**「JavaScript 表示 非表示 切り替え」「classList toggle」「CSS display none」「HTML CSS JavaScript 役割分担」というキーワードを使って調べてください。

### 問題1：ファイルをフォルダーへ分けるのはなぜか

最後に、小さな練習用ページと、画像やページが多いWebサイトでは、自分ならどのようなフォルダー構成を選ぶか、探しやすさと修正しやすさの観点から理由を書いてください。この問いには、制作物の規模によって複数の判断があります。

## 第8章　ブラウザの開発者ツールと問題の調べ方

主要なブラウザには、表示中のHTMLやCSS、JavaScriptのエラー、ファイルの通信状況などを確認できる「開発者ツール」があります。この章では、推測だけで直そうとせず、画面に出ている情報から原因を絞り込む方法を学びます。

### 問題1：ElementsとStylesでは何を確認できるのか

開発者ツールの「Elements」パネルでは、ブラウザが現在のページで認識しているHTMLを確認できます。「Styles」欄では、選択したHTML要素に適用されているCSSを確認できます。ブラウザによっては、日本語や別の名前で表示されることがあります。

自分で作ったページを開き、ページ上で右クリックして「検証」を選ぶなど、使用しているブラウザに合った方法で開発者ツールを開いてください。見出し要素を選択し、次の内容を確認して結果を記録してください。

- 見出しがどのHTML要素として表示されているか
- どのCSSセレクターから色や文字サイズが適用されているか
- 打ち消し線で表示され、別の指定に上書きされているCSS宣言がないか

次に、開発者ツール上で見出しの文字や色を一時的に変更し、ページを再読み込みしてください。変更が元に戻る理由を、元のHTML・CSSファイルを書き換える場合との違いから説明してください。

> **ヒント：**「ブラウザ 開発者ツール Elements Styles」「CSS 適用 確認 DevTools」「CSS 上書き 開発者ツール」「DevTools 変更 保存されない」というキーワードを使って調べてください。

### 問題2：Consoleのエラーから何が分かるのか

開発者ツールの「Console」パネルには、JavaScriptのエラーや、コードから出力した情報などが表示されます。次のコードでは、HTMLの`id`とJavaScriptのセレクターで大文字・小文字が一致していません。コード全体をHTMLの`<body>`内へ掲載順に置き、`<script>`要素がボタンより後になるようにしてください。

```html
<button id="showMessage">メッセージを表示</button>

<script>
  const button = document.querySelector("#showmessage");

  button.addEventListener("click", function () {
    alert("こんにちは！");
  });
</script>
```

実際にページを開いてConsoleを確認し、表示されたエラーを記録してください。この例のエラーは、ボタンを押したときではなく、ページを開いてイベントを登録しようとした時点で発生します。ブラウザによって文面は異なりますが、エラーが示している行番号と、値が見つからなかったことを表す`null`という表示に注目してください。

そのうえで、`document.querySelector()`が目的の要素を見つけられなかった理由と、ボタンを押しても処理が動かない理由を説明し、コードを修正してください。AIへ修正を依頼する場合、エラー文、関係するコード、期待する動作の三つをどのように伝えるか、具体的な依頼文も作ってください。

> **ヒント：**「JavaScript Console エラー 見方」「querySelector null addEventListener」「JavaScript id 大文字 小文字」「エラー 行番号 調べ方」というキーワードを使って調べてください。

### 問題3：症状に応じてどこを調べるのか

開発者ツールの「Network」パネルでは、HTML、CSS、JavaScript、画像などのリソースを読み込んだ記録を確認できます。開発者ツールを開いた状態でページを再読み込みすると、取得したファイルや、取得に失敗したファイルが一覧に表示されます。Webサーバー経由では`404`、パソコン上のHTMLを直接開いた場合は`ERR_FILE_NOT_FOUND`など、実行方法やブラウザによって異なるエラーが表示されることがあります。

次の症状について、最初にElements・Styles、Console、Networkのどこを確認するかを選び、そこで何を探すか説明してください。複数のパネルを使う場合は、確認する順番も考えてください。

- 文章は表示されるが、CSSの見た目が反映されない
- ボタンを押してもJavaScriptの処理が動かない
- HTMLには書いたはずの要素が画面に見当たらない
- 画像の代わりに壊れた画像の印が表示される

最後に、「AIが提案した修正をすぐ全部適用する方法」と「開発者ツールで事実を確認し、原因の候補を一つずつ試す方法」を比較してください。自分が不具合を調べるときの基本手順を、五つ以内のチェックリストにまとめてください。

> **ヒント：**「DevTools Network 使い方」「404 CSS 読み込めない」「JavaScript デバッグ 手順」「Webページ 不具合 切り分け」というキーワードを使って調べてください。
