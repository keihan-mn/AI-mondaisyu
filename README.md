# 自習問題ビューアー

`02-自主勉強課題/` 配下の問題を読み、問題ごとにMarkdownで回答できるローカル専用ビューアーです。回答途中の内容はブラウザへ自動保存され、完成・未完成を問わずMarkdownファイルとして保存またはダウンロードできます。

## 必要なもの

- Node.js 22.13.0以上
- npm
- このリポジトリのローカルコピー

## 初回セットアップと起動

```bash
git clone <PrivateリポジトリのURL> AI-mondaisyu
cd AI-mondaisyu
npm install
npm run dev
```

ターミナルに表示された `http://127.0.0.1:5173/` をブラウザで開きます。外部サーバーやログインは使いません。

## 回答する

1. 左側の「問題」から教材を選びます。
2. 各問題の回答欄へMarkdownで入力します。「入力」と「プレビュー」を切り替えられます。
3. 下書きは約0.3秒後にブラウザの `localStorage` へ自動保存されます。
4. 「回答を保存」を押すと、`answers/<教材名>/` に日時付きの新しいMarkdownファイルを作ります。既存回答は上書きしません。
5. 「Markdownをダウンロード」は、現在の回答をブラウザから直接ダウンロードします。ローカル保存とは別の操作です。
6. 左側の「回答」へ切り替えると、保存済み回答を閲覧できます。

未回答の問題も回答Markdownへ出力され、`未回答` と明記されます。教材が更新された場合も下書きは消さず、画面上に更新通知を表示します。

## 新しい問題を取り込む

作業前に必要なファイルをコミットまたは退避したうえで、次を実行します。

```bash
git pull
npm install
npm run dev
```

`answers/` と `node_modules/` はGit管理されません。ブラウザ下書きもリポジトリとは別に保持されます。教材更新後に画面へ通知が出たら、問題文の変更を確認してから回答を続けてください。

## 問題Markdownの形式

- 保存場所: `02-自主勉強課題/**/*.md`
- 章: `## 第N章　章題`
- 問題: `### 問題N：問題名`
- ヒント: 問題末尾の `> **ヒント：** ...`

互換性のある問題作成手順は `.claude/skills/creating-self-study-questions/SKILL.md` にあります。

## 検証

```bash
npm test
npm run build
```

`npm test` は問題解析、回答Markdown、下書き保持、保存APIの排他的保存と安全性を検証します。`npm run build` はTypeScript検査と本番ビルドを行います。

## データと安全性

- 個人回答は `answers/` 配下へ保存され、`.gitignore` によりGit管理されません。
- 保存APIは実在する問題ファイルだけを入力元として許可します。
- 保存先とファイル名はサーバー側で決め、パストラバーサル、別オリジン、不正JSON、過大要求を拒否します。
- ローカル利用を前提としており、共有サーバーへの公開機能はありません。

## GitHub接続について

ローカルリポジトリは `main` ブランチで管理します。GitHubの所有者を決め、GitHub CLIを再認証した後に、`AI-mondaisyu` という名前のPrivateリポジトリを作成して `origin` を登録してください。
